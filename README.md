# UDP-Based-Reliable-Protocol

## Project Overview

This repository contains a refactored, modular version of my university project. Originally delivered as a single, monolithic Python script of about 1 600 lines—leveraging UDP sockets and multithreading—it was developed over a full academic semester to meet the official deadline. While modest by today’s standards, it provided a substantial learning curve. 

The repo also includes a simple Lua dissector for Wireshark to parse and visualize the custom UDP protocol.

---

This repository is part of my university coursework for the Computer and Communication Networks course (September 2024 – January 2025).
